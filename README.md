# Handcrafted Haven

Handcrafted Haven is a full-stack web application designed to connect artisans and crafters with customers who appreciate unique handmade products.

The platform allows sellers to create profiles, upload handcrafted items, and interact with buyers through reviews and ratings.

## Project Purpose

The purpose of this project is to create an online marketplace that supports local artisans while providing users with a simple and enjoyable shopping experience for handmade products.

## Features

* Seller Profiles
* Product Listings
* Product Images and Descriptions
* Reviews and Ratings
* Product Search and Filters
* Responsive Design
* Accessibility Support
* Secure Authentication

## Repository Setup

Clone the repository:

```bash
git clone https://github.com/darma2006/handcrafted-haven.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
